**Completed:** Week 2 — Reference Data

## Changes
- Added `StudentGrade` entity for managing school grade levels
- Added `StudentClass` entity for managing classes/sections within grades
- Added `Student` entity for student records (preparation for Week 3)
- Added `Ledger` entity for Chart of Accounts with 20 default accounts seeded on startup
- Added `Category` entity for transaction categories linked to ledgers
- Added `BusinessInfo` entity for school/business configuration
- Created `GradesController` with full CRUD operations (`/api/v1/grades`)
  - GET /api/v1/grades - List grades with pagination and sorting
  - GET /api/v1/grades/{id} - Get single grade
  - POST /api/v1/grades - Create grade (Admin, Staff)
  - PUT /api/v1/grades/{id} - Update grade (Admin, Staff)
  - DELETE /api/v1/grades/{id} - Soft delete grade (Admin only)
- Created `ClassesController` with CRUD and student assignment (`/api/v1/classes`)
  - GET /api/v1/classes - List classes with pagination and sorting
  - GET /api/v1/classes/{id} - Get single class with student list
  - POST /api/v1/classes - Create class (Admin, Staff)
  - PUT /api/v1/classes/{id} - Update class (Admin, Staff)
  - DELETE /api/v1/classes/{id} - Soft delete class (Admin only)
  - POST /api/v1/classes/{classId}/students - Assign student to class
  - DELETE /api/v1/classes/{classId}/students/{studentId} - Remove student from class
- Created `LedgersController` with CRUD operations (`/api/v1/ledgers`)
  - GET /api/v1/ledgers - List ledgers with type and active filters
  - GET /api/v1/ledgers/{id} - Get single ledger
  - POST /api/v1/ledgers - Create ledger (Admin, Accountant)
  - PUT /api/v1/ledgers/{id} - Update ledger (Admin, Accountant)
  - DELETE /api/v1/ledgers/{id} - Soft delete ledger (Admin, Accountant)
- Created `CategoriesController` with CRUD operations (`/api/v1/categories`)
  - GET /api/v1/categories - List categories with type and active filters
  - GET /api/v1/categories/{id} - Get single category
  - POST /api/v1/categories - Create category (Admin, Accountant)
  - PUT /api/v1/categories/{id} - Update category (Admin, Accountant)
  - DELETE /api/v1/categories/{id} - Delete category (Admin, Accountant)
- Created `BusinessInfoController` with GET/PUT (`/api/v1/business-info`)
  - GET /api/v1/business-info - Get business information
  - PUT /api/v1/business-info - Update business information (Admin, Accountant)
