## Changes

### Milestone 7 — Year-End & Import

- **Added Year-End Close endpoint** (`POST /api/v1/ledgers/year-end-close`)
  - Zeroes revenue and expense ledgers by posting closing entries
  - Transfers net profit/loss to Retained Earnings (ledger 3000)
  - Idempotency guard prevents double-close of same year
  - Records closed year in `ClosedYears` table
  - Creates journal entries with `JournalType = 'closing'`

- **Added Year-Beginning Open endpoint** (`POST /api/v1/ledgers/year-beginning-open`)
  - Posts opening entries for permanent accounts (asset, liability, equity)
  - Guard: requires prior year to be closed first
  - Validates opening debits = opening credits (balance check)
  - Creates journal entries with `JournalType = 'opening'`

- **Student CSV Import** (`POST /api/v1/students/import`)
  - Already implemented in Week 3-4
  - Returns imported/skipped counts with error details
  - Supports multipart/form-data file upload

### Milestone 8 — Polish

- **Consistent Pagination**
  - Updated `LedgersController.GetLedgers()` to use standard pagination parameters:
    - `page` (default: 1)
    - `perPage` (default: 10, max: 100)

## Notes / blockers encountered

- EF Core InMemory doesn't support database transactions (`BeginTransactionAsync`)
  - Solution: Added `ConfigureWarnings(b => b.Ignore(InMemoryEventId.TransactionIgnoredWarning))` to test setup
  - This allows tests to run but doesn't test actual transaction rollback behavior
  - For production, SQL Server transactions work correctly

- Test isolation was challenging with InMemory database
  - Solution: Used unique database names per test instance with incrementing counter
  - Added `DisableParallelization = true` to test collection to prevent race conditions
