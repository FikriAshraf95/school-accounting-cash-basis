# 2026-04-11_week4
**Completed:** Week 4 — Reports

## Changes
- Implemented Journal Entries list endpoint (`GET /api/v1/journal-entries`)
  - Supports filtering by ledgerId, journalType, dateFrom, dateTo
  - Includes related Ledger, Transaction, and CreatedByUser data
  - Returns paged results with metadata

- Implemented Trial Balance report (`GET /api/v1/ledgers/reports/trial-balance`)
  - Optional year filter to limit entries to specific fiscal year
  - Calculates debit/credit amounts based on account type (debit-normal vs credit-normal)
  - Returns list of trial balance items with totals and balance check flag
  - Only includes ledgers with activity or non-zero balance

- Implemented Ledger Summary by Year (`GET /api/v1/ledgers/summary/{year}`)
  - Shows opening balance, total debits/credits, net change, and closing balance per ledger
  - Calculates category totals (Assets, Liabilities, Equity, Revenue, Expenses)
  - Handles opening entries from year-beginning-open process
  - Supports first-year operation (no prior year closing)

- Implemented Student Transaction Report (`GET /api/v1/students/report`)
  - Supports filtering by gradeId, classId, dateFrom, dateTo
  - Returns student summary with total income, total expense, transaction count, and balance
