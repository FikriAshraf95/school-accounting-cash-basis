# School Accounting System (Frontend)

A Vue.js frontend application for managing school financial operations. This is the frontend client for a .NET backend API.

## Features

- **Student Management** - Register, track, and manage student records and reports
- **Payer Management** - Manage fee payers (parents/guardians)
- **Class Management** - Organize students into classes
- **Accounting Module**
  - Income/Deposits tracking
  - Expense/Payment management
  - Chart of Accounts (Ledgers)
  - Financial Reports (Balance Sheet, Profit & Loss, Trial Balance)
  - Transaction history

## Tech Stack

- Vue 3 + TypeScript
- Vite
- Pinia (State Management)
- Tailwind CSS + shadcn-vue
- Chart.js
- Axios

## Getting Started

### Prerequisites

- Node.js 20+
- npm or yarn

### Installation

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Type check
npm run type-check
```
