## Notes / Blockers Encountered

1. **TypeScript Type Issues with API Responses**
   - Fixed by casting API responses to `any` where needed
   - This is a temporary fix; proper typing could be added later

2. **Select Component Value Types**
   - Select component expects string values but IDs are numbers
   - Fixed by converting IDs to strings for Select and back to numbers for API calls

3. **Input Component Null Value Issues**
   - Input component doesn't accept null values
   - Fixed by creating separate form interfaces without null types and converting nulls to empty strings on initialization

4. **Router Type Errors**
   - Routes with `name` but no `component` caused TypeScript errors
   - Fixed by commenting out incomplete routes for future weeks
